- **`image-gen.mjs` robustness.** A multi-line `## World` in `BRIEF.md` is now read whole instead of being cut at its first line (existing plates composed with a multi-line world get a new hash and are regenerated once; single-line worlds are unaffected). Requests time out after 120 s and a timeout is retried once like a network error. An unknown provider, a missing or unreadable plan file, and two `use` files sharing a basename now exit 2 before any request instead of "no key ... undefined" or exit 4. Plates and copied files are written through a temp file and a rename, so a killed run no longer leaves a truncated plate that is treated as cached forever.
