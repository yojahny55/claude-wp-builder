- **The remaining `bash -c` calls that carried the project path or the web user are quoted safely too.** The `test -f`, `mkdir -p`, `wp core download`, `cd && docker-compose/ddev/lando/wp-env`, `setfacl`, store-kit sync and `wp eval-file` calls in `/wp-create`, `/wp-woo-setup` and the plugin-profile reference still interpolated `${PROJECT_PATH}` (and `${WEB_USER}`) into a double-quoted `-c` string, so a value holding a single quote, `$()` or a backtick could run code. They now use a fixed single-quoted `-c` script with the values as positional arguments; `$WP` is handed to the child shell as an environment variable so it still expands to the command plus its flags. The quoting check now fails on any `bash -c "..."` that interpolates either variable and runs every new call shape with a hostile path.
