# `__cinematic__` starter theme

Cinematic scroll-driven WordPress starter. Persistent video stage + N scenes that scroll-scrub on desktop and autoplay-loop on mobile. Designed to be hydrated by the `wp-cinematic` agent from a `cinematic-scroll-kit` schema.

## Placeholders

Tokens replaced by `/wp-cinematic-init` / `/wp-init --mode=cinematic`:

| Token | Replaced with |
|---|---|
| `__starter__` | project slug (kebab-case) — used as theme folder name |
| `__STARTER__` | PHP prefix (snake_case) — function/constant prefix |
| `__TEXTDOMAIN__` | i18n text domain |
| `__VERSION__` | theme version (default `0.1.0`) |

## Files generated at scaffold time

Most files in `inc/`, `fields/`, and `template-parts/cinematic/` are **generated** by the `wp-cinematic` agent from `schemas/scene.json`. They carry a header:

```php
<?php
// AUTO-GENERATED by wp-cinematic from cinematic-scroll-kit schemas/scene.json v{version}
```

To preserve hand edits across regeneration, wrap them in:

```php
// @user-block:start <id>
... your code ...
// @user-block:end <id>
```

## Files NOT regenerated (hand-author safe)

- `functions.php` (loader entrypoint)
- `style.css` (theme header)
- `assets/css/cinematic.css` (base stage + scene styles — copy of kit's canonical `templates/style.css`)
- `assets/js/cinematic-engine.js` (copy of kit's `templates/main.js`)
- `header.php`, `footer.php` (standard parts)

These are kept in sync with the kit via `/wp-cinematic-init --update-kit`, which copies fresh from the installed kit and shows a diff before overwriting.

## Engine boot

1. `inc/cinematic-loader.php` adds `body.has-cinematic` when the page has cinematic content.
2. Adds `body.is-mobile-cinematic` based on viewport (`max-width: 1024px`) at server render — re-evaluated client-side on resize.
3. Engine reads `data-*` attributes from each `[data-scene-id]` block — no extra fetch needed.
4. Reduced-motion: if `matchMedia('(prefers-reduced-motion: reduce)').matches`, engine never boots — posters render instead.

## Mobile fork

- Stage `<video>` stack hidden via CSS.
- Each scene block renders an inline 9:16 `<video autoplay muted loop playsinline>`.
- IntersectionObserver with `rootMargin: -35% 0% -35% 0%` toggles `.is-active` class for scene focus.
- No GSAP / Lenis loaded on mobile (~80 KB JS saved).
